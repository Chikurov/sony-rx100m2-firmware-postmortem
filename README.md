## Кратко

- Разобран апдейтер `Update_DSCRX100M2V110.exe`: PE32 + контейнер с
  подписью PKCS#7 (Sony, DigiCert), 25 файлов.
- Внутри — контейнер `UFU` (`DATV`, `PROV`, `UDID`, `FDAT`, `DEND`).
- `FDAT` — AES-128-ECB, ключ `E3B0C442…B924`, блоки 1024 Б с CRC16.
- Расшифровано: cramfs (updater body 31.01.52) + TAR (49 записей).
- Разделы: `nflasha3` → FAT12 (ядро 2.6.29.6, initrd AXFS, загрузчики),
  `nflasha8` → ext2 (533 файла, ARM EABI5).
- Собрана кастомная `/usr` и залита. **Камера перестала грузиться.**

## Почему не сработало

| Причина | Статус |
|---|---|
| Патч был мёртвым: реальный код в `libObj.so`, а не в `wrapperArtFilter.so` | ФАКТ |
| TPZL пересобран с literal-кусками 65535 вместо эталонных 4096 | ФАКТ (отклонение) |
| Метаданные ext2: `uid/gid 0/0`, даты 2026 вместо 56086/1000 и 2014 | ФАКТ (второстепенно) |
| Точная причина отказа на стороне камеры | НЕИЗВЕСТНО (нет консоли) |

Структурные проверки (CRC16/CRC32/DEND/суммы/`fsck`) проходили — но они
не проверяют совместимость с декомпрессором устройства. Именно это и
стало ловушкой.

## Инструмент, который ловит эту ошибку

```
$ python3 verify_tpzl.py reference.tpzl
literal chunk sizes: {4096: 710}          PASS

$ python3 verify_tpzl.py custom.tpzl
literal chunk sizes: {65535: 1394, 1: 1394}   ← вне эталона
```

## Чек-лист перед прошивкой (для других)

1. Доказать, что правка **исполняется** (`DT_NEEDED`, `dlopen`,
   дубликаты символов).
2. Менять минимум байт; остальное — байт-в-байт.
3. Перекодировать только затронутые блоки, строго в границах эталона.
4. `verify_tpzl.py --ref` — literal-размеры должны совпадать с эталоном.
5. Пересборка без изменений = байт-в-байт оригинал.
6. Вернуть `uid/gid/права/даты`, проверить `fsck` и чтение обратно.
7. Убедиться, что откат **не зависит** от изменяемого раздела.
8. Только потом — устройство и явное подтверждение.

## Что удалось разобрать

UFU/FDAT/TPZL, FAT12/ext2, AXFS (562 файла), UXC, база DSP `0xC3440000`
и таблица 118 параметров. Подробности — в [docs/](docs/).

## Последствия

Камера выставлена на продажу как донор. Стоимость потери — около $500.
Ответственность за решение прошивать — на агенте: оценка риска была
необоснованной.

## Ограничения

- Причина отказа не подтверждена логом устройства.
- Не проверено, является ли 4096 жёстким лимитом декомпрессора.
- Устройство не восстановлено.
