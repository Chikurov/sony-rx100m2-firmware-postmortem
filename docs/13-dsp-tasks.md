# DSP: задачи и подсистемы (по строкам образа)

ФАКТ: строки в `av-cam.bin` содержат имена задач RTOS. Роли — ПРЕДПОЛОЖЕНИЕ
по названиям.

| Имя | Встречается | Вероятная роль |
|---|---|---|
| `TskAvifEvent` | 4 | события AV-интерфейса |
| `TskAvifVsync` / `TskAvifVSync` | 4 | вертикальная синхронизация |
| `TskAvifTable` | 3 | таблицы AV-интерфейса |
| `TskPcpMain` | 1 | главная задача PCP |
| `TskAvcEncVideoMain` | 1 | кодирование видео |
| `tsk_sdf` + `tsk_sdf_rec_00..03` | 2+ | запись (4 канала) |
| `tsk_sdf_retouch` | 2 | ретушь |
| `tsk_sdf_jpegsort` | 2 | сортировка JPEG |
| `tsk_sdf_vsync` | 2 | синхронизация SDF |
| `tsk_rawdev_sequence` | 2 | последовательность RAW |
| `tsk_capcon_sequence` | 2 | управление захватом |
| `tsk_syshs` | 2 | системная задача |
| `tsk_front` / `tsk_front_vsync` | 1+1 | фронтальная подсистема |
| `TaskHS` | 2 | high-speed задача |

Также в строках: `osal_*` (RTOS API), `[CDIAG][TSK]`, `LiroSequencer`,
`SelectCpu`, `act_tsk`.

## Память (наблюдения)

| Диапазон | Что |
|---|---|
| `0xC3440000` + файл | код/данные образа (6,45 МБ) |
| `0x010C0000+` | окно параметров (118 записей, ID `0x1F0..0x340`) |
| `0xC3C7xxxx` | глобальные структуры состояния |
| `0xC3A75xxx` | глобальные таблицы/буферы |

## Оговорка

Имена задач — строковые константы; привязка к адресам кода не
установлена. Роли — предположения.
