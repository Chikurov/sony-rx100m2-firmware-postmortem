# Модули `sabin` (DSP-алгоритмы)

60 файлов в `/usr/sabin`, имена `sa_*.bin` (например `sa_bfnr.bin`,
`sa_jpeg_enc_1core.bin`, `sa_camdsp_bayer.bin`, `spica_*_step1/2.bin`).

## Заголовок (по двум файлам)

| Смещение | Поле | `sa_bfnr` | `sa_jpeg_enc_1core` |
|---|---|---|---|
| 0x00 | magic | `AA 0A 13 91` | то же |
| 0x04 | u16/u16 | `0x0002`,`0x0100` | то же |
| 0x08 | u16/u16 | `0x000B`,`0x0100` | `0x01E1`,`0x0100` |
| 0x0C | u16/u16 | `0x0008`,`0x0001` | `0x0002`,`0x0001` |
| 0x10 | u32 | 0 | 0 |
| 0x14 | имя (16 Б) | `SABFNR__0.01` | `SAJPGE_CLF4_` |
| 0x24 | u32 | `0x05000008` | `0x05000002` |
| 0x28 | u32 | 1 | 1 |
| 0x2C | u32 | 1 | 1 |
| 0x30 | u32 | 0 | 0 |
| 0x34 | имя (16 Б) | `BFNR____0.01` | `JPGENC_CLF4_` |

Значения 0x08/0x0C, вероятно, связаны с размером кода/секций
(ПРЕДПОЛОЖЕНИЕ). Второе имя — короткое имя модуля.

## Инвентарь

`data/inventory/sabin.txt` — 60 записей: имя, размер, SHA-256.

## Ограничения

Формат кода внутри модулей (ARM? DSP?) не разбирался: сигнатура не ELF,
точка входа и карта памяти неизвестны.
