# Исполняемые файлы `/usr/bin` и `/bin`

ФАКТ: в образе **нет** `/usr/bin`; весь пользовательский набор — в `/bin`
(36 записей, из них **28 ELF** исполняемых, остальное — ссылки/скрипты).

## Загрузчики

| `PT_INTERP` | Файлов |
|---|---|
| `/lib/libsonyld.so` | 26 |
| `//lib//libsonyld.so` (двойной слэш) | 1 |
| `/usr/glib/ld-linux.so.3` (glibc) | 1 (`orb-server`) |

То есть почти всё, кроме `orb-server`, грузится загрузчиком Sony.

## Символы

- `.symtab` сохранён только у `athtestcmd` и `wpa_supplicant`;
- у `orb-server` `.symtab` нет, но `.dynsym` богатый (5 265 `FUNC`) —
  поэтому его функции читаемы.

## Данные

`data/binaries.tsv` — путь, размер, INTERP, число `DT_NEEDED`, наличие
`.symtab` для всех 28 ELF.
