# UXC — ресурсный контейнер UI

ФАКТЫ по `rootfs/share/app/*.uxc` (string_english.uxc, string_russian.uxc,
color_cmn.uxc, style_cmn.uxc).

## Заголовок

```
"uxc" (3 байта) | версия 0x07 (1 байт) | u32 0
u16 0x0008 | u16 count | u32 hash? | таблица u16 ...
```

Пример `string_english.uxc` (200 812 Б):

```
75 78 63 07 00 00 00 00 08 00 27 00 4e f3 34 01
таблица: 0000 0002 0006 000A 000D 0010 ... (есть разделители FFFF)
```

Значения таблицы малы (0,2,6,10…) — это не байтовые смещения.
Семантика таблицы — **НЕИЗВЕСТНА**.

## Записи строк

```
u16 id; u16 flags (0x1E04); строка (ASCII или UTF-8); NUL; выравнивание до 4
```

Проверено:

| Файл | id | flags | Строка |
|---|---|---|---|
| string_english.uxc | 0xE061 | 0x1E04 | `Standard` |
| string_english.uxc | 0xE062 | 0x1E04 | `Vivid` |
| string_english.uxc | 0xE06B | 0x1E04 | `Sepia` |
| string_russian.uxc | 0xEF1B | 0x1E04 | `Иллюстрация` |

ID идут последовательно внутри блока (0xE052…0xE06E в блоке стилей).
Строки NUL-терминированы, длина отдельно не хранится.

## Практика

- Замена «в длину» безопасна: смещения не пересчитываются.
- Если строка короче — остаток забивается NUL (терминатор сохраняется).
- `flags = 0x1E04` во всех проверенных записях; смысл поля неизвестен.

## Цветовые записи (color_cmn.uxc)

`color_cmn.uxc` (244 Б) содержит записи по 8 байт:

```
u16 id; u16 type; u32 value
```

Начиная с 0x44: `id = 0x4000, 0x4001, …`, `type = 0x3A09`,
`value` — RGBA (например `0x000000FF` чёрный, `0xDD0000FF` красный,
`0x00DD00FF` зелёный, `0x0000DDFF` синий, `0xCCCCCC80` полупрозрачный).

Перед записями (0x40) — u32 `0x2A`; его смысл не подтверждён.

## Что не разобрано

- таблица u16 в заголовке;
- связь `id` с UI-экранами;
- назначение `color_cmn.uxc` / `style_cmn.uxc` (малые файлы, иная структура).
