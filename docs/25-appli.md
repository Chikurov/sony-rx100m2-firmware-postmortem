# Дополнительные полезные нагрузки пакета

## `0110_backup/SYSAVIP-DSC/EQ/*.bin` (10 файлов)

- размер каждого: **549 745 Б**;
- магия **`BK2`** по смещению `0x0C`;
- далее счётчики: `0x18A`, `0x4085`, `0x14CE0`, `0x71691`, `0x35C2FD4`;
- имена: `CX63710C6_UC2.bin`, `..._J1`, `..._KR2`, `..._TW6`,
  `CX63711C6_CEH`, `..._RU3`, `..._E32`, `..._HK1`, `CX63711C5_CN1`,
  `..._CE3` — привязка к регионам/моделям.

Похоже на региональные калибровки (цвет/тон) в контейнере BK2 —
ПРЕДПОЛОЖЕНИЕ: содержимое не сверялось с DSP.

## `0800_appli/tmp/images/*.uxc` (5 файлов)

- магия **`uxd\x07`** (не `uxc\x07`!) — отдельный вариант ресурса;
- заголовок: `08 00`, `2E 00`, `C3 52 2C 01`, таблица `u16` со значениями
  `0, 5, 10, 15, 20 …`.

То есть `uxd` — ресурс с изображениями/данными, а `uxc` — со строками и
цветами. Формат таблицы не разобран.

## `0800_appli/tmp/config.spec`

Список элементов с версиями, например:

```
element /132H_Dsc-Diadem/... REL_SET-DSC132H_DSC-EQ-132H_130509_01
element /AVBiz-AudioProcessor_131H/... REL_AVBIZ-AUDIOPROCE_COMMON_130228_01
...
```

Формат: `element <путь>... <ID версии>`.

## `0800_appli/setting/facedmy.bin`

Заполнен повторяющимся `0x2180` — заглушка (dummy) для лица/детекции
(ПРЕДПОЛОЖЕНИЕ).
